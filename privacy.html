Privacy

Color converter runs in this page and in its optional browser extension. Convert CSS hex, RGB, and HSL colors and calculate an accurate OKLCH value.

Data

Your input and results stay in browser memory. The tool has no analytics, account system, advertising code, or remote API.

Storage and permissions

The extension requests no permissions. The app does not write your input to localStorage, cookies, or a database.

Hosting

Opening the web version makes the normal request needed to load files from GitHub Pages. Processing begins after those files load and does not upload your content.

Questions

Report a privacy or security issue through the repository issue tracker.
